## 1. 自动失败项

任一项出现，当前候选版本不得晋级：

- 编造源文没有支持的人物、事实、引语、数字或经历；
- 复制来源的独特连续表达、固定署名，或让读者误以为来源作者亲自发布；
- 把单篇事实、产品结论、人物细节或视觉配额写成所有文章都必须遵守的规则；
- 忽略用户指定的任务、读者、渠道或输出格式；
- 为追求风格分数删除会改变结论的条件，或把不确定内容写成确定事实；
- 授权、隐私、版权或关键事实存在明确阻断，却把结果标记为可发布/已验证。

自动失败项优先于总分。增加免责声明不能修复核心事实、结构或版权错误。

## 2. 默认评分卡

先按每项 0—10 评分，再乘以权重：

| 维度 | 权重 | 主要问题 |
|---|---:|---|
| 任务与读者适配 | 15 | 是否完成用户目的，是否对目标读者有效 |
| 结构与因果推进 | 15 | 事件、问题、证据、转折和结论是否相互推动 |
| 语言、声音与节奏 | 15 | 人称、句长、口语度、密度和声音是否可辨 |
| 说理机制与证据功能 | 15 | 类比、数字、对话、细节是否承担清楚的论证功能 |
| 场景、情绪与作者在场 | 10 | 有证据的生活后果、观察和服务动作是否被保留 |
| 价值交付与行动收束 | 10 | 是否让读者获得判断，结尾是否与任务自然相连 |
| 泛化与表层自由度 | 10 | 能否适配其他题型，是否避免固定模板坍缩 |
| 原创、事实与安全 | 10 | 是否可追溯、不过度复制、不冒充且边界清楚 |

总分：

`总分 = Σ（维度得分 ÷ 10 × 权重）`

默认门槛：无自动失败项、总分 ≥85；跨文章验证时，“泛化与表层自由度”不得低于 7/10；单篇只能标记 `provisional`，不能因为高分宣称泛化。

## 3. 评分解释

### 3.1 0—3：失败

任务偏离、结构断裂、声音完全泛化、证据失真，或有明显安全问题。

### 3.2 4—6：可读但不稳定

部分机制出现，但依赖模板、解释悬空、场景被削弱，或只在源文上有效。

### 3.3 7—8：合格

主要机制被保留，候选稿完成任务，局部仍需精修；规则有条件且可解释。

### 3.4 9—10：稳定

候选稿既保留底层功能又保留表层自由度；跨题型仍有效，且没有以复制或虚构换取相似感。

评分时同时写三句话：

1. 最高分维度的具体证据；
2. 最低分维度和造成失分的一个原因；
3. 下一轮只应改变哪一条规则。

### 3.5 baseline 与 candidate

候选稿不必在每一项都高于 baseline；必须看总分、最低维度和留出集。若 candidate 在源文上提高、在留出集下降，判定为过拟合，拒绝该修改。

## 4. 测试提示模板

保存为 `evals/test-prompts.json`。`expected` 只写可观察行为，不写答案：

```json
[
  {
    "id": "happy-path-01",
    "source": "sample-a.md",
    "prompt": "根据给定文章提炼的写作 Skill，重写这篇同主题文章；保留事实，不复制独特句子。",
    "expected": "完成用户任务，保留核心结构机制，输出原创且可追溯的稿件。",
    "type": "same-task",
    "holdout": false
  },
  {
    "id": "transfer-01",
    "source": "sample-b.md",
    "prompt": "将同一写作机制用于不同题型，允许改变开头、结构和结尾形式。",
    "expected": "迁移底层机制，不强行复制源文表层模板。",
    "type": "cross-type",
    "holdout": true
  }
]
```

至少包含一个 `same-task` 典型提示和一个 `transfer` 迁移/复杂提示。单篇样本的 `transfer` 只能标记为压力测试，不得作为独立文章泛化证据。用户未确认测试范围时，先停在测试设计阶段。

## 5. 进化日志

`results.tsv` 可使用以下表头：

```tsv
timestamp	run_id	version	prompt_id	old_score	new_score	lowest_dimension	status	eval_mode	note
```

`status` 使用 `baseline`、`keep`、`revert`、`blocked`；`eval_mode` 使用 `full_test` 或 `dry_run`。分数保留一位小数，只有严格提升且留出集没有明显退化才写 `keep`。

每轮改动记录格式：

```text
假设：把规则 R-STRUCT-02 改为条件规则，能减少家庭故事的模板化。
证据：sample-a 第3段、sample-c 结尾；sample-b 没有该特征。
变更：只调整题型路由，不新增固定小标题。
预期：跨题型维度 +1，源文声音不下降。
结果：总分 82.0 → 86.5；holdout 7.4 → 7.6；决定 keep。
```
