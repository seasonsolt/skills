# 克制自述叙事（draft / provisional）

> **状态：暂定（单篇校准）。** 本文件刻意命名为 `draft-SKILL.md`，不会被自动发现加载。
> 全部规则来自 1 篇样本，尚未通过第二篇独立文章的迁移验证；证据见
> [`../reports/evidence-ledger.md`](../reports/evidence-ledger.md)，验证结论见
> [`../reports/evolution-report.md`](../reports/evolution-report.md)。
> 在补齐第二篇同题材样本并通过回归前，**不要**重命名为 `SKILL.md`。

## 1. 写作前必读

开始写之前先读 [`../references/style-profile.md`](../references/style-profile.md)，
取回 M1—M8 八条机制、旋钮表、题材路由和反模式。本文件只管流程，不重复机制细节。

## 2. 输入检查（缺任一项先问，不要先写）

1. **材料**：真实经历／访谈记录／虚构设定，哪一种？有没有可用的具体细节（时间、地点、
   人、数量、物件）？
2. **任务契约**：目标读者、发布渠道、字数、格式、必须保留的事实、明确的禁区。
3. **人物边界**：文中是否出现可识别的真人？是本人、是已授权的受访者，还是第三方？
4. **虚构标注**：如果是虚构，用户是否接受在文末标注？

材料里没有具体细节时，不要开始写。本风格全部靠细节承重，没有细节只会产出模仿腔。

## 3. 安全边界（硬阻断，优先于一切风格目标）

- **不对可识别的在世真人**叙述未经证实的金钱往来、性、疾病、生育、犯罪或家庭冲突情节。
  加"纯属虚构"落款**不解除**这一限制。命中时停下来，向用户说明，并给出两个替选：
  改为匿名化／复合人物，或改为已公开且可引用的事实。
- 涉及未成年人、患者、客户的细节先脱敏，再判断公开范围。
- 不编造用户材料中不存在的人物、引语、数字、经历。需要虚构时，必须由用户明确授权，
  并在交付时标出哪些是设定。
- 引用他人原话必须有原始记录；没有记录只能转述并标明来源不确定。

## 4. 用户任务优先级

显式任务约束 **永远高于** 本 Skill 学到的风格规则。冲突时按此顺序让步：

`用户指定的事实 / 字数 / 格式 / 结论 > 安全边界 > 任务可读性 > 风格机制 > 表层旋钮`

用户要求"必须有三条可执行建议"时，就写三条直陈的建议，即使这会打断克制感。

## 5. 题材路由

按 [`../references/style-profile.md`](../references/style-profile.md) §3 选择机制组合，
**并从同一张表的"开场形式"列取回本篇该用的开头**（`R-OPEN-02`）：

- 长篇自述叙事 → 开场用 M1；M1—M8 全开；
- 短叙事 → 开场用 M1' 静止场景；M1'、M2、M4、M5/M5'、M7，去掉分节与物件线；
- 工作／事故复盘 → **开场结论前置**（第一屏给判断）；只用 M2、M4、M5'，
  **保留独立的结论段**；不要用 M1 开头；
- 说明、教学、服务文 → 开场把读者的问题前置；只借 M4；
- 营销稿 → 不用本 Skill。

判断不了题材时，问用户，不要默认按长篇叙事写。同一次会话连续写两篇时，第二篇的开头
不得与第一篇同形——这是本风格最先坍缩的地方（反模式 A7）。

## 6. 从材料到草稿（线性流程）

1. **列事实清单**：把材料里所有具体项抄成一张表——时间、地点、人、数量、物件、
   一句原话。写作只能从这张表取用。
2. **找交换**：这件事的核心冲突能不能还原成一次交换或一次代价？能 → M1；不能 → M1'。
3. **点名第三方**：清单里谁是被调度的无名者？给他一个工艺细节和一次自主判断。
   一个也找不到 → 用 M5'，把代价落到物的损耗上。**这一步不能跳过。**
4. **排时间线**：允许倒装（当下 → 起源 → 顺叙 → 回到当下）；长稿用 `---` 硬切，
   节与节之间不写过渡句。
5. **写动作，不写情绪**：先按 M2 把每一处情绪点替换成动作；实在替换不了的先留空。
6. **铺回声**：前三分之一放一个空景意象，结尾以更大规模复现（M6）。没有落空结构就跳过。
7. **减法**：删掉所有形容词副词，只把删掉后读不懂的加回来。删掉结尾的点题句。
8. **对表**：逐项核对第 1 步的事实清单，确认没有多出任何一项。

## 7. 证据门槛

| 内容 | 门槛 |
|---|---|
| 数字（金额、次数、时长） | 必须来自材料，或标注为设定。不取整、不修饰 |
| 直接引语 | 必须有原始记录；否则转述并标注 |
| 人物动机、心理 | 只写可观察行为；不替真人断定动机 |
| 推断 | 用"我不知道""我没有问"承认信息缺口，不用推测填补 |

不确定的一律降级为"我不知道"。本风格允许承认不知道，这本身就是机制的一部分。

## 8. 交付前硬约束自检

按 [`../references/style-profile.md`](../references/style-profile.md) §5 逐条过一遍，
并额外确认：

- [ ] 字数、格式、渠道符合用户要求；
- [ ] 用户点名必须保留的事实全部在文中；
- [ ] 没有材料之外新增的人物、引语、数字；
- [ ] 没有可识别真人被写入未证实情节；
- [ ] 启用机制 ≤ 材料承载力（短稿三到四条），每条有辩护，弃用的有理由（负空间条款）；
- [ ] 材料里有第三方或可损耗之物时，M5 或 M5' 已出现（反模式 A1）；
- [ ] 逐个数字答得出"替哪句没说的话站岗"；无任何派生算术（反模式 A2）；
- [ ] 开场形式取自题材路由表，且与上一篇不同形（反模式 A7）；
- [ ] 情绪形容词已清零或有明确理由保留；
- [ ] 结尾没有点题句；
- [ ] 复盘／说明类文本保留了独立结论段。

## 9. 输出格式

**默认**：直接给正文，不加前言、不加"以下是……"。正文之后附一个折叠的交付说明：

```text
字数：<n>
启用的机制及辩护：<每条一行：机制 → 这份材料为什么撑得起它>
主动弃用的机制及原因：<逐条>
数字清单：<每个数字一行：数字 → 它替哪句没说的话站岗>
来自材料的事实：<逐条>
标注为设定的内容：<逐条，或"无">
```

交付说明是**辩护不是清点**：不得以机制覆盖率为成绩（rubric v2 自动失败项第 8 条）。
材料贫瘠（无数字、无第三方、无时间跨度）时，正确行为是降档少用机制或按下面的失败
格式暂停，不是把机制硬塞进去。

**失败时**（材料不足、安全阻断、任务与风格冲突）：不要硬写。按此格式报告：

```text
状态：暂停
原因：<材料不足 / 安全阻断 / 任务冲突>
缺什么：<具体到需要用户补的项>
可选方案：<两个>
```
