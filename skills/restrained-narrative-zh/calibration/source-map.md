## 1. 文章任务

叙事 + 反转读者预期。表面是"富豪谈恋爱花了多少钱"的八卦清单，实际任务是让读者把
"挥霍"重新理解为"一次十九年没有被通过的好友申请"，并在结尾把私人失恋升格为
"什么都没有发生"的一般命题。

## 2. 读者问题与核心冲突

- 读者起初相信：这是炫富／桃色爆料，叙述者是加害者或冤大头，二选一。
- 作者让读者改变的判断：金额不是主题，金额是**度量单位**；真正的主题是"所有这些钱
  买到的都是空场"。读者最后同情的不是叙述者，也不是女主角，而是那些被钱调度的第三方
  劳动者。
- 冲突不是"给不给五千万"，而是"叙述者能不能承认自己感觉不到什么"（数心跳一段）。

## 3. 结构因果

| 位置 | 做了什么 | 因果作用 |
|---|---|---|
| 开篇 3 句 | 卵子重量 / 现金重量 / 一句话把两者接成抵押关系 | 用两个不可比的物理计量建立"一切可称重"的世界观 |
| 第 1 节尾 | 清洁工照常打扫空楼层，"登记上写着有人" | 第一次把代价落到第三方身上，给出全文母题"空场" |
| 第 2 节 | 倒回 2007 年校内网好友申请未通过 | 揭示动机源头；把后文所有金额都变成"申请的加价" |
| 第 3—4 节 | 见面、包场、彩礼、贴胶带、索取升级 | 每一次给予都伴随一次拒绝或一次落空，推进而非罗列 |
| 第 5 节 | "让我想想" + 外部裁决 + 十一秒沉默 | 唯一一次拒绝；决定权被外包，叙述者失去主动性 |
| 尾声 | 结账：胶带痕、放掉的燃油、未拆的针、退不了的定金 | 用账单复盘全部代价，情绪不出场 |
| 最后 4 行 | 一百万人涌来又退去 → "什么都没有发生" | 与第 1 节"空场"环形闭合，私人事件升格为一般命题 |

## 4. 语言行为

- 第一人称，短句为主，逗号少，句号密；形容词极少。
- 单句成段极多："我说好。""我沉默了。""我没有说。"——形成节拍器。
- 对话不用引号，统一写作"她说，X。"／"我说好。"；应答方长期只给三个字。
- 金额、时长、件数用中文数字（五千万、三十卷、四十几页），年份日期用阿拉伯数字。
- 从不写情绪词。情绪由无意义的身体动作外显：把手机屏幕朝下、把手放在胸口数心跳、
  把提醒划掉、把指甲锉放回抽屉。
- 章节之间用 `---` 硬切，不写过渡句。

## 5. 证据与场景的功能分工

| 材料 | 承担的功能 |
|---|---|
| 精确到荒诞的数字（二十六个人、三十卷又补二十卷、十一秒） | 用精确度替代评价；作者不说"过分"，只说数量 |
| 第三方劳动者（清洁工、贴胶带的两个女孩、拍房视频的人的影子、领钱的一家三口） | 道德重心。他们有工序、有讨论、有名字（"她知道那两个女孩叫什么。我不知道。"） |
| 廉价小物（2007 年的 QQ 图、指甲锉） | 跨十九年的时间锚，承担不可挽回感 |
| 结算账单（胶痕、放掉的燃油、未拆的促排针、二十万定金） | 用会计口径做情绪总结，避免抒情 |
| 重复句式（"我说好。""什么都没有发生。"） | 节拍与环形结构的显性标记 |

## 6. 交易与安全边界

- 源文点名在世公众人物（艺人及其亲属实名、企业家本人），并叙述未经证实的金钱往来、
  勒索与代孕情节。**该做法列为 `safety` 反模式，不迁移**：训练出的 Skill 必须禁止
  对可识别真人做同类未证实叙述，"纯属虚构"声明不解除这一约束。
- 源文的独特连续表达（开篇重量对照、"一座失去皇后的凡尔赛宫"、结尾一百万人）
  **只作定位引用，不进入 Skill 的句子库**。
- 源文事实（人物、金额、地点、日期）不构成新文章的事实授权。
- 源文的固定署名与"不设版权"落款属于 `incidental`，不迁移。
