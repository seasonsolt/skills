# 去 AI 味：工具、开源库与提示词（2026-07 检索 · 2026-08-05 增补 v2 流程）

面向**小红书 / 公众号**写作的"去 AI 味"实操资源。核心立场：**目标是"真像人"，不是"骗过检测器"**——后者是跟检测模型的军备竞赛，越往后越难，且伤号。优先用"注入真人声音"的方法，别碰纯"过检测"路子。

## v3 工序（2026-08-05 晚定稿；v2 + human-writing 客观闸门）

新增主力：[KKKKhazix/human-writing](https://github.com/KKKKhazix/human-writing)（739⭐ · 中文专用 · MIT）。
三点核心：**材料五件套**（非虚构 1200 字先列 5 件带来路的具体材料，列不出就写短）；**段段推进**（每段必须新增事实/动作/例子/后果，换说法不算）；**硬禁令**（正文禁冒号[除直接引语]、禁破折号、禁翻案腔全部 7 种外衣、同构排比 ≤2 项、黑话禁词表[含"价值闭环/底层逻辑/降本增效"等]）。
自带 `scripts/check_prose.py` **客观检查器**——humanizer 评分是主观的，它可重复、可当闸门。实测：v2 工序 44/50 的稿子仍被它抓出 2 冒号 + 1 翻案变形 + 句长鼓点。

1. **起草前取声音样本**：从 `posts/` 挑 1-2 篇高分已发布正文（如 gpt56-why-slow 46/50）当 few-shot；材料按 human-writing 五件套先备齐。
2. **第一遍**：humanizer-zh 24 项 + 中文 7 项（上表）清除。
3. **第二遍**：human-writing 七遍审稿法过一轮（谁在说/推进/表演中文/词序停顿/禁用项/核事实/查结尾）。
4. **客观闸门**：`python3 check_prose.py 稿件.md` 必须 0 失败；警告项人工判断。脚本在 human-writing 仓库，用时 gh api 拉取或本地 clone。
5. **主观门槛**：humanizer-zh 50 分制 ≥40 + 金句密度 ≤1/300 字 + 小节不同构。
6. 事实/数字/出处/第一人称经历红线照旧。卡面文案也过一遍黑话禁词表（"价值闭环"这类词别上卡）。
7. XHS 取舍：emoji 分段标记保留（用户偏好，属版式不属文风）；标题可保留对照句式（标题是按钮，不是散文）。

## Humanizer-zh 的 24 项痕迹（速记）

- **内容**：夸大意义/遗产/趋势；堆知名度媒体报道；-ing 结尾的肤浅分析；宣传广告腔；模糊归因（"专家认为"）；公式化"挑战与展望"
- **语言**：AI 高频词（此外/至关重要/深入探讨/彰显/格局/赋能…）；回避"是"（用"作为/代表/充当"）；否定式排比（不仅…而且 / 不是…而是）；强凑三段式；同义词循环；虚假范围（从 X 到 Y）
- **风格**：破折号过度；粗体过度；内联标题+冒号列表；标题大写（中文不适用）；emoji 装饰；弯引号
- **沟通**：协作痕迹（希望有帮助/当然！）；知识截止免责；谄媚语气
- **填充**：填充短语、过度限定、通用积极结论

**5 条核心**：删填充词 / 打破公式结构 / 变节奏（两项优于三项、结尾多样）/ 信任读者 / 删金句。

## 即用提示词（已按小红书/公众号调过）

```
你是一个说人话的中文写作者。把下面的文字改得像真人随手写的，不像 AI。铁律：
1【禁用词】综上所述/总而言之/值得注意的是/首先其次最后/不仅…而且/更是/随着/
  在当今/赋能/助力/深入探讨/揭秘/一起来看看/进行了…——一个都不许出现。
2【禁"而是"】少用"不是…而是…"的对仗句式和协作路标词（首先/其次/综上）。
3【标点预算】少破折号、少冒号、少加粗；emoji 最多 1-2 个（公众号 0 个）。
4【句式】长短句交替，多短句和口语；第一人称，允许犹豫、自嘲、跑题一句。
5【结构】不许一二三四教科书式排列；情绪和结论前置。
6【语气】冷静克制、带点反讽（韩寒那种平铺直叙里下刀），不煽情、不喊口号。
7【保真】事实、数字、出处一个字都不能改，也不许替我编"亲测经历"。
只输出改写后的正文，不要解释。
```

> 最见效的是第 1、2 条：AI 味八成来自高频词 + 对仗腔。

## 与本 skill 的衔接

`copywriting.md` 的"去 AI 味"工序原是"过一道 DeepSeek 重写"。可升级为：
- **最省事**：正文写完跑 `/humanizer-zh`，比裸 DeepSeek 稳，自带 24 项自检 + 评分。
- **最贴风格**：用 OUBIGFA 的 good-writing 模式喂几篇目标作者文章，长期复现同一声音。
- ⚠️ 两者都别碰"过检测"那条线——目标是真像人，不是骗机器。DeepSeek/任何模型都爱替你编第一人称经历，红线是"亲测/我的用法必须真"。
