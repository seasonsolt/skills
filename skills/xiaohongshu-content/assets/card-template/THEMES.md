# 卡片主题库 · 写笔记时自动选主题

做卡片前（方案 B 渲染，或给图像模型写 P1 prompt 前）先过这张路由表，把结果写进 `note.md`：
`theme: <name>` + 一句选择理由。同一篇笔记 P1→Pn 只用一个主题。

## 路由规则（按优先级从上到下，命中即停）

1. **系列一致性**：属于已有系列的笔记沿用该系列既定主题——【AI前沿速递】= `vintage`。
   搜索号的识别度长在搜索结果页里，系列内不轻易换肤；确要换须在 note.md 写明理由。
2. **题材关键词**（单篇、无系列约束时）：

   | 主题 | 命中关键词 |
   |---|---|
   | `receipt` | 价格 / 涨价降价 / 成本 / 账单 / token 计价 / 订阅费 / 省钱——凡是"要算账"的题材 |
   | `matrix` | 终端 / CLI / Codex / API / agent / 开源权重 / 算力 / 黑客 / 安全 / 泄漏 / 极客文化 |
   | `bulletin` | 官宣 / 发布会 / 撕逼 / 站队 / 下架 / 塌房 / 里程碑事件——情绪贴（推荐引擎） |
   | `vintage` | 新模型深度解读 / 机制拆解 / 避坑指南——搜索深帖 |
   | `paper` | 轻教程 / 清单 / 语录 / 个人思考——调性轻的内容 |

3'. **反重复检查（2026-08-06 加）**：路由选定后，回看最近 2 篇的 `theme`。若与上一篇相同**且题材也相近**（例如连着两篇都是涨价），换用次优主题——主页 grid 上连续两张同款封面会被读成重复发文。系列一致性让位于此。

3. **引擎兜底**（关键词都不明显时）：要评论和情绪冲击（推荐引擎）→ `bulletin`；
   要收藏和长尾（搜索引擎）→ `vintage` 或 `paper`。

## 用法

```bash
cp -r assets/card-template posts/<你的笔记>/cards
# build_cards.py 里改 THEME / BADGE / CARDS，然后：
python3 build_cards.py
```

- 主题只换 CSS，class 词汇表不变：同一份 CARDS 换 THEME 即整套换肤。
- `.red` 语义是"主题强调色"（matrix 下是琥珀），`.hl` 是"主题高亮"，写卡面时照常用。
- **P1 默认使用当前可用的图像模型**（skill 硬规则不变）：prompt 风格用上表"种子"那一列，保证封面和内页同一气质；中文标题照旧 HTML 叠字。图像工具不可用或连续失败 2–3 次时，才用本模板全 HTML/CSS 渲染。
- 加新主题：`themes/<name>.css`（复刻 class 词汇表）+ 可选 `themes/<name>.decor.html`（卡内装饰层，渲染时自动注入）+ 本文件路由表加一行。

预览图见 `previews/`（五主题同一通用内容渲染，直观对比）。
