### 0.1 离线假设（无法询问作者/用户，取保守默认）

- A1 输出语言：现代简体中文，中文引号“”；不使用繁体、旧字形、文言虚词。
- A2 字数口径：用户未写口径时按“非空白字符数（含标点）”计；用户写了以用户为准。
- A3 不新增人物：叙述者“我”若素材里没有，就不凭空加一个旁观者；改用素材中已有人物作观察者，或第三人称外部有限视角。依据：任务契约“不得新增人物”。
- A4 对白：只能把素材中已经发生的言语写成直接引语，可调整措辞，不得新增信息、态度或新的说话行为。依据：任务契约“不得新增引语”。
- A5 渲染与事实的边界：时间、地点、天气、年龄、金额、次数、伤病、结局都算事实，只用素材给的；允许的渲染限于素材中已存在的人、物、动作的可见质地、动作分解、声响与停顿。
- A6 结尾规则证据不足：sample-3 被截断，结尾机制只有 2 篇证据，相关规则降为 `medium`。
- A7 交付说明：只在出现偏差（字数不足、素材缺口、任务冲突）时附在正文后，正常情况只交正文。
- A8 §7.1 素材追问：交互环境下可追问 1—2 个具体时刻；离线或用户不答时按素材写并在交付说明标注“缺少现场素材”。

## 2. 文章地图（Trainer §6.1，转述，不抄原句）

### sample-1（酒店常客的潦倒与消失）
1. 任务：叙事；借一个人的被取笑与消失，揭示围观者的冷漠。
2. 读者判断的改变：读者先跟着笑，后来发现笑声本身是残忍的，而叙述者也在笑的人里。
3. 结构因果：先立酒店格局（谁站着喝、谁坐着喝、价钱）→ 少年伙计的位置与无聊 → 主角是唯一“穿长衫却站着喝”的人（规则的违例者）→ 两次被取笑的场面，各以群体的愉快收尾 → 与孩子的两段小互动（叙述者轻慢他）→ 一句独立短段点出“有他无他一样” → 闲谈中得知他被打断腿 → 最后一次出现，用手走路 → 欠账在节令间被重复提起，随后不再提起 → 叙述者用“大约”推断死亡。
4. 语言：第一人称回忆；长段铺陈 + 极短独立段；逗号串联动作链；群体对话短促；叙述者不评论残忍。
5. 证据与场景：欠账数字、记账板、长衫、满手泥是核心物件；对话承担暴露（取笑、闲谈链）；情绪几乎不直写。
6. 安全：人物、地名、钱数、物件、标志句全部属原作专有，不进入 Skill。

### sample-2（一次乘车途中的小事）
1. 任务：叙事 + 自省；一件小事改变了叙述者对自己的判断。
2. 读者判断的改变：读者先接受叙述者对车夫“多事”、对老妇“装样”的判断，随后看着这些判断被车夫的行动推翻。
3. 结构因果：开头以对“大事”的疲倦立反差 → 风中乘车 → 老妇被车把带倒 → 叙述者内心的冷算计（被写出来）→ 车夫不理叙述者，扶人走向警所 → 叙述者对车夫背影的感知发生变化，自身的“小”被逼出 → 掏一把钱交出 → 随即自问这钱的含义 → 结尾陈述长期影响（明说惭愧与自新）。
4. 语言：第一人称回忆；短段多；内心独白直接写出（我想……）；关键对白极短。
5. 证据与场景：一把钱、皮袍、背影、风的停息承担功能；转折由一句问话和一个扶人动作完成。
6. 安全：同上。负例：结尾直陈道德结论，与 sample-1 的留白收束不同。

### sample-3（回乡卖屋与儿时玩伴重逢，截断）
1. 任务：叙事；以今昔对照写人与人之间的隔阂。
2. 读者判断的改变：读者随叙述者期待重逢，再在一声称呼里看到身份差距不可逾越。
3. 结构因果：阴冷归途与记忆中故乡的落差 → 卖屋的事务 → 母亲提起故人，触发明亮的童年记忆长段 → 邻人登场，今昔面貌对照，夸张指责与顺手拿物 → 故人到来：面貌、帽子、手逐项与记忆对照 → 一声敬称造成断裂 → 故人之子被看作“当年的他” → 故人诉苦、只是摇头 → 拣东西 → 启程前的忙乱（截断）。
4. 语言：第一人称回忆；风俗括注解说；记忆段华彩，当下段灰冷；“愕然”式短句；比喻取自日常器物。
5. 证据与场景：项圈/帽子/手/礼物/拣走的器物承担今昔与阶层对照；称呼承担转折。
6. 安全：同上。
