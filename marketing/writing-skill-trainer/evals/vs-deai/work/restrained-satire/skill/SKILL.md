# 克制讽刺短篇

## 1. 何时使用

使用：用户给出虚构素材包（情节、人物、事件、可选的视角）和字数要求，要一篇现代背景的中文短篇小说，希望冷静、克制、带讽刺。

不使用：没有素材、要求你自己编故事；要求模仿文言或旧白话腔调；要求署名为某位真实作者或声称出自其手；写真实人物的纪实或报道。遇到这些情况，说明本 Skill 不适用，或只按普通写作处理。

## 2. 写作前

**先完整读取 `references/style-profile.md`。** 那里是写法机制、条件规则、旋钮和反模式；本文件只管流程和边界。

## 3. 输入检查与边界

1. 确认素材、字数区间、计数口径；用户未写口径时，按“非空白字符数（含标点）”计。
2. 确认视角：素材指定了叙述者或视角就照用；没指定按 §5 路由选择。
3. 素材是虚构材料，按虚构处理。若素材明显涉及真实人物或真实群体，只写素材给出的内容，不加任何贬损细节。
4. 身份与版权：本 Skill 只迁移写法机制。正文不署任何作者名，不加落款日期，不借用任何已知作品的人物、名字、标志句或意象，不把任务写成某篇名作的翻版。

## 4. 任务契约（高于一切风格规则）

1. **保留每一条素材事实**：人物、关系、事件、顺序、结局、素材里的数字和原话，一条都不能丢，也不能改。
2. **不新增**：不新增事实、事件、人物（包括无名旁观者和叙述者“我”）、数字（时间、年龄、金额、次数）、引语和对白内容、结局、人物的决定或承诺。
3. **对白**：只能把素材中已经发生的言语写成直接引语，可以调整措辞，不得增加信息或态度；素材没给言语，就不写台词，用动作。
4. **允许的渲染**：素材中已存在的人、物、动作的可见质地、动作的分解、停顿和声响；以及叙述的顺序、详略和视角。时间、地点、天气、伤病、价格属于事实，只用素材给的。
5. **字数**：成稿必须落在区间内。素材不够撑到下限时，先用允许的渲染把已有事实写足；仍不够，就贴近下限交付，并在交付说明里写明，不得扩写事实凑字。
6. **用户的显式要求**（视角、语气、格式、禁区）高于本 Skill 的任何风格规则。

## 5. 路由：按素材选主要机制

先判断素材属于哪一类（可兼有），再从 style-profile 里选两三个主要机制落地，不必全用：

| 素材特征 | 类型 | 优先机制 |
|---|---|---|
| 有一个反复被旁人议论、取笑或忽视的人；有群体 | 旁观型 | R-03 平叙残忍、R-04 物件、M-01 闲谈链、R-05 复现 |
| 观察者本人卷入，并有他自己的判断或态度 | 自我照见型 | R-02、M-02、R-07 短转折、R-10 自问式收束 |
| 素材有两个时间点，或同一人前后身份变化 | 今昔对照型 | R-06 同项对照、R-05 复现、R-07 短转折 |
| 都不明显 | 默认 | R-01、R-04、R-07、R-10 |

## 6. 工作流

1. **列事实清单**：把素材逐条拆成编号事实（人物、关系、事件、顺序、结局、数字、原话、物件）。这是交付前核对的依据，不写进正文。
2. **素材检查**：找出素材里的具体时刻（在哪、谁做了什么、当时什么反应）和可用物件、言语。若关键场面只有概述、没有任何具体动作或物件，而你能与用户交互，先追问 1—2 个具体问题（例如“他把钱递过去时，是放在桌上还是递到手里？”）；不能追问或用户不答，就按素材写，并在交付说明写“缺少现场素材”，不得自行补写场景、动作或情绪。
3. **定叙述位置**（R-01）：选观察者，不新增人。
4. **选承重物**：从素材里挑一两样能承担判断、能复现的物件、称呼或动作（R-04、R-05）。
5. **排顺序**：开头立处境或从第一个事件进入（R-11）；中段用长段铺陈与短段交替推进（R-08）；把转折安排在一句短话或一个动作上（R-07）。
6. **写初稿**：用现代口语化书面语；判断交给物件与动作；该平静处平静（R-03）；不能确知处降调，但素材写明的事实照实写（R-09）。
7. **收束**（R-10）：停在事实、缺席或叙述者的自问上，不训话。
8. **自检**：按 §8 逐项核对，不通过就改，改完再核一遍。

## 7. 证据门槛

- 每一个事实性陈述都要能对应到事实清单里的某一条；对应不上的，删掉或改成素材已有内容。
- 每一句直接引语都要能对应到素材里的某次言语。
- 每一个数字都必须出自素材，原样保留。
- 推测（叙述者的猜想、他人的心思）必须带不确定标记，且不得与素材事实冲突。
- 素材里的各项事实互相矛盾时，不自行裁决，按素材原样保留较明确的一方，并在交付说明中指出矛盾。

## 8. 交付前自检

1. **长度**：按口径计数，落在区间内（或已在交付说明中写明为何贴近下限）。
2. **必备事实**：事实清单逐条打勾，全部在正文中出现且未被改写含义。
3. **零新增**：没有新人物、新数字、新台词、新事件、新结局、新的人物决定或承诺；时间、地点、天气只来自素材。
4. **风格**：过一遍 style-profile §5 风格自检，尤其是无仿古、无原作意象、无方法术语、无结尾训话。
5. **格式**：按用户要求的格式；未要求时输出可选短标题 + 正文，不加小标题、编号、落款或作者名。

## 9. 输出

默认只输出：可选标题 + 正文。

仅在出现以下情况时，在正文后另起一行写 `---`，再写简短交付说明（不计入正文字数）：

- 字数贴近下限或无法达到区间（写明原因：素材体量不足）；
- 缺少现场素材（§6 第 2 步）；
- 素材自相矛盾，或用户要求与契约冲突（写明如何处理）。

无法完成时（没有素材、要求冒充作者、要求超出契约），不写正文，直接说明原因和需要用户补充什么。

## 10. 缺素材时跳过，不补写

style-profile 里每条需要具体内容才能执行的规则（闲谈链、偏见被推翻、复现、今昔对照、惯例开头），素材不支持时一律跳过该动作，改用素材已有的东西；绝不为了让规则成立而补造人物、台词、物件、数字或情节。
