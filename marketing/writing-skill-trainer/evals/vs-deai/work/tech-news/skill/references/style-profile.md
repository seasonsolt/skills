# 风格档案：中文科技新闻报道

本档案描述写作机制，不提供可复制的句子。所有示例都是为说明机制而虚构的占位写法（机构用"甲公司""乙研究院"等代称），**不是事实，不得写进稿件**。规则编号对应 `reports/evidence-ledger.md`。

## 1. 核心机制（invariant）

### 1.1 摘要式导语（R-LEDE-01/02）

- 第一段回答"谁 + 做了什么 + 最重要的内容是什么"。主语是机构或人物，谓语是具体动作（发布、宣布、表示、推出、接入、提交等）。
- 导语可再带 2—3 个最高权重要素：发布物是什么性质、谁参与、覆盖哪些方面，或全文的两条主线。其余细节一律下沉。
- 不用场景描写、设问、背景铺垫、行业感叹开篇。
- 示意（虚构）：甲公司宣布在其翻译软件中加入语音实时转写功能，首批支持六种语言，面向企业用户开放。
- 降级：材料没有明确的发布方或动作时，以材料中最具体的那条事实作导语主干，不补造发布方。

### 1.2 倒金字塔顺序（R-ORDER-01）

按新闻权重递减排列：

1. 导语；
2. 主体身份或场合背景（这是什么机构/报告/产品，在什么场合说的）——也可放到结尾作解释；
3. 关键发现、表态或功能，最重要的在前；
4. 支撑数字、案例、逐项细节；
5. 影响、风险、关切（材料有才写）；
6. 收尾（见 1.8）。

检验：从任一段之后截断，前文仍然独立成立且包含最重要的信息。

### 1.3 段内先总后分（R-ORDER-02）

- 一段先给一句概括，再接数字或逐项例子。
- 多个并列例子（多款产品、多个场景、多个领域）用连续短段，每段一项，以相同的引导结构开头（如"在某场景中，……"），不用项目符号。
- 降级：材料只有孤立数字或孤立细节时直接陈述，不为它编一句概括判断。

### 1.4 归属：观点挂在信源名下（R-ATTR-01/02）

- 判断、预测、评价性形容词（显著、强劲、令人关注等）一律以"信源 + 中性动词"引出：报告显示/指出/认为、某人表示/称/说/建议、某公司介绍。
- 引述动词在中性范围内轮换，避免连续三句同一个动词；不用痛批、坦言、豪言、直言、怒斥等带立场的动词。
- 报道者本人不下判断，不写"值得注意的是""毫无疑问"等插入语。
- 示意（虚构）：乙研究院在报告中称，相关模型的推理能耗仍偏高。（"偏高"属于研究院，不属于报道者。）
- 降级：材料中的评价没有标明来源时，按材料原意保留，不编造"业内人士""分析人士"等信源，并在交付说明注明"来源未标明"。

### 1.5 不确定性标记原样保留（R-NUM-02）

- 估算写"估计/约"，计划写"将/计划/预计到某时"，提案写"将提出/建议"，演示所得写"在演示中"，可能性写"可能"。
- 不把计划写成已完成，不把演示能力写成已普遍可用，不把估计写成精确值。
- 反向同理：材料写成确定事实的，不自加"据悉""可能"来软化。

### 1.6 中性书面语体（R-REG-01）

- 第三人称叙述；叙述中不出现"我/我们/你/您"。材料里的宣传文案若使用第二人称，改为"用户"等第三人称，或作为该公司原话放入引号。
- 不用感叹号、反问、设问、口号式句子、网络流行语。
- 句子以陈述句为主，中长句与短句交替；并列信息可在一句中用顿号串联。

### 1.7 术语与背景（R-REG-02）

- 机构、报告、技术名首次出现写全称，括注缩写或外文原名，之后用简称。
- 读者可能不熟悉的会议、制度、项目，用一句中性解释交代它是什么（放在第二段或结尾均可）。
- 降级：材料没给全称或原名时不自拟，不自行翻译外文名。

### 1.8 收尾（R-END-01）

- 收尾仍是信息：信源自己的总结、事件背景解释，或信源给出的意义/下一步。
- 不写报道者的总结、展望、呼吁或"此举标志着……"式定位，除非这句话在材料中有明确信源。
- 降级：材料没有可收尾的总结或背景时，以最后一条细节事实自然结束。

### 1.9 版式（R-FORM-01）

- 第一行：短标题（名词短语或"主体 + 动作"，一般不超过 15 字），不加任何媒体名、栏目名。
- 第二行：电头【YYYY年M月D日讯】，日期取材料中的发稿/事件日期；材料没有日期则省略电头。
- 正文不分小标题；段落 1—4 句，一段一个信息单元。段长、段数是旋钮，不是配额。

## 2. 条件规则（conditional）

| 规则 | 触发条件 | 做法 | 不触发时 |
|---|---|---|---|
| R-ORDER-03 多信源分块 | 材料有 2 个以上发言人/机构 | 每个信源一块：身份 → 转述要点 → 原话或数字 → 建议条目；块序按职务高低与新闻权重 | 单一信源不分块，按 1.2 顺序写 |
| R-ATTR-03 人物称谓 | 材料中有具名人物 | 首次"机构 + 职务 + 姓名"或"身份同位语，姓名"；再次出现可缩为"职务 + 姓名"或姓名 | 材料只给姓名时只写姓名，不补职务、头衔 |
| R-ATTR-04 直接引语 | 材料给出原话（引号内、或标明为原话） | 通常先一句转述要点，再接原话；引语前后标明说话人；引语一字不改，统一用“”，内层用‘’ | 材料没有原话时全部转述；绝不把转述加上引号变成原话 |
| R-NUM-01 数字配参照 | 材料给出同一指标的两个年份、两类主体或目标与现状 | 把两个数字放在同一句或相邻句里对照，显示幅度 | 只有单个数字时直接陈述；不自行计算倍数、增幅、占比、差值 |
| R-BAL-01 进展与风险并列 | 材料同时含进展和风险/担忧/批评 | 先进展后风险，各自署名，篇幅大体相称 | 材料没有风险时跳过，不补写"也引发担忧" |

## 3. 缺口与未知（R-GAP-01，user_constraint）

- 材料明确写了"未披露/未公布/尚不清楚/拒绝置评"的事项：用一句中性陈述写出，并挂到对应主体，例如（虚构）"甲公司未公布该功能的收费标准"。位置放在与该事项相关的段落里，不单独成段堆砌。
- 不推测未知的原因，不补"外界猜测""或将"等内容。
- 材料没有提到的信息，不主动声明"未披露"（那等于新增一个关于缺口的事实），也不列"未知清单"。
- 材料内部数字或说法互相矛盾时，两种说法都按来源写出（"甲称……，乙的数据显示……"），不自行裁定，并在交付说明注明。

## 4. 旋钮（不是配额）

- 段落数量与长度、是否在第二段还是结尾解释背景、引述动词的具体选择、是否用并列短段举例、标题是名词短语还是动宾结构。
- 根据材料决定，不要每篇都用同一种开头动词、同样的段数或同样的收尾形式。

## 5. 反模式

- 来源模糊的归属："人们担忧""业内认为""有分析指出"——材料没有这个信源就不要写。
- 无署名的定性收尾："此举意味着……""这标志着……的新阶段"。
- 宣传腔：第二人称、"一键搞定""颠覆体验"、感叹号、形容词堆叠。
- 为凑字数扩写背景、行业概况、技术科普，或重复导语内容。
- 自行换算数字（倍数、百分比、人民币折算、日期推算），哪怕算得对。
- 简繁混用、引号样式混用、复刻错别字。
- 在正文里说出本档案的方法用语（如"倒金字塔""先总后分""以下按新闻权重排列"）——这些是给写手的指令，不是稿件内容。

## 6. 风格自检

- 只读第一段，能否说出谁做了什么、最重要的内容是什么？
- 每一个判断性词语，能否指出它属于哪个信源？
- 计划、估计、演示、提案的标记是否都还在？
- 有没有一个数字、一个人名、一句引语、一个评价在材料里找不到？
- 结尾一句是不是信息，而不是报道者的感想？
