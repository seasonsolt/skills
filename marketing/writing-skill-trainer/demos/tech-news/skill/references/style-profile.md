# 风格档案：中性科技新闻

## 核心机制

### 1. 导语：概括最新最重要事实
- 条件：所有报道。
- 动作：第一段用一句话点明事件主体、动作和时间。
- 证据：S1, S2, S3。

### 2. 倒金字塔结构
- 条件：所有报道。
- 动作：先写最重要的信息，再按重要性递减排列细节。
- 证据：S1, S2, S3。

### 3. 归因明确
- 条件：涉及观点、数据、引语。
- 动作：明确标注来源（如“报告称”、“部长称”）。
- 证据：S1, S2。

### 4. 中立语气
- 条件：所有报道。
- 动作：使用中性词汇，避免主观评价；用“称”、“表示”等动词。
- 证据：S1, S2, S3。

### 5. 数据与引语的使用
- 条件：有具体数据或引语。
- 动作：直接引用或转述，并注明出处；数据用于支持事实。
- 证据：S1, S2。

## 语气旋钮
- 正式程度：高（避免口语化）。
- 情感色彩：中性（避免褒贬）。
- 句式：多用陈述句，少用感叹句。

## 反模式
- 避免使用“令人惊叹”、“重大突破”等主观形容词。
- 避免将观点混入事实。
- 避免使用第一人称。

## 最终自检
- [ ] 导语是否包含核心事实？
- [ ] 信息是否按重要性排列？
- [ ] 所有观点和数据是否归因？
- [ ] 是否保持中立？
- [ ] 是否未添加事实包之外的内容？
