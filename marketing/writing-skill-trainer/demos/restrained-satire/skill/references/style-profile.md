# 冷峻讽刺风格档案

## 核心机制

### 1. 具体生活细节作为讽刺载体
- 用日常物件、价格、动作等细节暗示社会现实，而非直接评论。
- 示例：酒的价格、茴香豆、长衫与短衣。
- 证据：S1, S3

### 2. 叙述距离
- 采用第一人称旁观者（如酒店伙计）或亲历者，但保持冷静、不介入。
- 通过“我”的有限视角，让读者自行判断。
- 证据：S1, S2

### 3. 反差制造讽刺
- 人物身份与行为矛盾（如孔乙己穿长衫却站着喝酒）。
- 语言与事实矛盾（如“窃书不能算偷”）。
- 证据：S1, S3

### 4. 对话推进与人物塑造
- 用对话展现人物性格和关系，避免直接描述。
- 对话中常含重复、误解或自欺。
- 证据：S1, S2, S3

### 5. 克制的情感表达
- 情感通过动作、环境暗示，不直接抒发。
- 如“我似乎打了一个寒噤”表达震惊。
- 证据：S2, S3

### 6. 结尾留白
- 以开放式或模糊的结尾收束，如“大约孔乙己的确死了”。
- 证据：S1

## 语气旋钮
- 叙述者态度：冷漠、同情、自嘲（可调）。
- 讽刺强度：含蓄到明显（可调）。
- 细节密度：疏朗到密集（可调）。

## 反模式
- 避免直接说教或评论。
- 避免过度夸张的修辞。
- 避免使用样本中的原句或专名。

## 最终自检
- 是否每个讽刺点都有具体细节支撑？
- 是否保持了叙述距离？
- 是否避免了模板化开头或结尾？
