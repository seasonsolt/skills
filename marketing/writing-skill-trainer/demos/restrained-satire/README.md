### 训练证据摘要

- S1: 用酒店格局、酒价、短衣帮等细节构建社会背景，讽刺等级差异。
- S1: 孔乙己“站着喝酒而穿长衫”的反差，揭示其身份尴尬。
- S2: 第一人称“我”的内心活动与车夫行为对比，形成自我讽刺。
- S2: 通过“我”的愧疚和自省，展现道德觉醒。
- S3: 故乡的萧索与记忆中的美好对比，讽刺现实变迁。
- S3: 闰土从活泼少年变为麻木中年，通过外貌和对话展现。

### 暂定规则

- 使用第一人称旁观者视角时，叙述者应保持一定距离，不直接评价。
- 在人物对话中，通过重复或误解来增强讽刺效果。
- 结尾可采用模糊或开放式，留给读者思考空间。

### 主动排除的表层特征

- 特定人名（孔乙己、闰土等）
- 具体地名（鲁镇、京城等）
- 特定物品（茴香豆、长衫等）
- 特定句式（如“多乎哉？不多也”）
- 特定数字（如十九个钱）
